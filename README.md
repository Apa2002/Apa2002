## Featured research

### 🧠 HiCaps-EEG | Visual category decoding from EEG

For my master's thesis, I developed HiCaps-EEG, a **PyTorch** framework combining CLIP-guided hierarchical visual representations with capsule-based EEG features. The model uses **transformer-based contextual encoding**, **cross-attention**, and **reliability-aware fusion** to integrate complementary neural representations.

I evaluated the framework under **unseen-stimulus and unseen-subject protocols**, with additional temporal and category-level decoding analyses.

This work connects neural signal analysis with visual representation learning to investigate EEG-based visual category decoding.

**Related manuscript:** First-author manuscript **submitted to a conference**.
[View research overview and results →](https://github.com/Apa2002/HiCaps-EEG)

## Selected projects

### 📝 Medical image captioning with BLIP + LoRA

Fine-tuning a pretrained BLIP model with LoRA on **10% of the ROCOv2 training data** to generate captions for radiology images. The project includes comparison with the model without fine-tuning and evaluation using BLEU, METEOR, ROUGE-L, and CIDEr.

[View project →](https://github.com/Apa2002/MedImageCaption_BLIP_LoRA_ROCOv2)

### 🔬 Medical image captioning with ViT-GPT2 + LoRA

Exploring a vision–language encoder–decoder model with LoRA fine-tuning for radiology image captioning on ROCOv2, including quantitative evaluation and qualitative inspection of generated captions.

[View project →](https://github.com/Apa2002/ViT-GPT2-for-Medical-Captioning)

### 🩻 Brain tumor segmentation

Brain tumor segmentation in MRI scans using a **VGG16-based encoder–decoder** on the LGG dataset, with Dice and IoU evaluation and visualization of predicted masks.

[View project →](https://github.com/Apa2002/UNet_VGG-TumorSeg)

### 🌙 Sleep apnea prediction
